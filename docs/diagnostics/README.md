# Diagnostics

The source generator checks templates and formats as it compiles them. Every problem is a build error with its own
ID, and the IDE links each one to its page here.

| ID | Title |
|----|-------|
| [TDSL001](TDSL001.md) | Template must be partial |
| [TDSL002](TDSL002.md) | Template can't be a ref struct |
| [TDSL003](TDSL003.md) | Template must be a top-level type |
| [TDSL004](TDSL004.md) | Unsupported construct in Build |
| [TDSL005](TDSL005.md) | Template must implement exactly one template interface |
| [TDSL006](TDSL006.md) | Invalid format declaration |
| [TDSL007](TDSL007.md) | Template nodes can only be used in Build |
| [TDSL008](TDSL008.md) | A nested template needs a context its parent doesn't have |
| [TDSL009](TDSL009.md) | A template is only a node in Build |

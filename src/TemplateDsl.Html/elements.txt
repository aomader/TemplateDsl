# The HTML elements and their attributes. tools/GenerateHtmlElements.cs turns this into C#.
#
#   name: attribute attribute?      "?" marks a boolean attribute, which has no value
#   name: attribute~                "~" marks text for people to read: strings, or numbers and dates in the current culture
#   name: attribute:any             takes strings, or numbers and dates in the invariant culture. Others take only strings
#   name: attribute:int             takes only that type, also :double and an enum such as :InputType. :bool writes the word true or false
#   name: attribute:number          takes any number. :number|text takes strings too, and :date, :month, :time, :datetime those
#   name.variant!: attribute        a variant with a fixed type attribute, such as input.email, which becomes H.InputEmail
#   name!: attribute                "!" marks a void element, which has no closing tag or children
#
# Attributes on the "global" line go on every element. Event handlers such as onclick are left
# out on purpose: running a dynamic value as code should never be one parameter away.

global: id:any class style title~ lang dir role slot nonce tabindex:int accesskey contenteditable:bool draggable:bool spellcheck:bool translate popover hidden? inert? autofocus?
